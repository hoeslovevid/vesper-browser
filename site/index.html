Now 0.1.2 for Windows

The evening browser.

A quieter Firefox. Collapsed tabs, spaces, and motion that stays out of the way — with privacy on by default and add-ons from addons.mozilla.org.

Download for Windows View source

Free and open source, MPL-2.0. Windows SmartScreen may warn until the installer is signed.

Chrome that recedes.

Vesper keeps Zen’s architecture — vertical tabs, spaces, split view — and starts with a slim icon rail so the web is the first thing you see.

Collapsed sidebar

Tabs live as a quiet icon rail. Expand it when you need names; collapse it when you need canvas. The URL bar stays close to the tabs.

Firefox add-ons

Vesper keeps Firefox’s application ID, so extensions from addons.mozilla.org install the same way they do in Firefox.

Spaces

Separate work, weekend, and late-night sessions without mixing cookies, tabs, or mood.

Updates from GitHub

About Vesper checks GitHub Releases, downloads the Windows installer, and launches it. No Zen update server in the middle.

Gecko, not Chromium

The engine is Firefox. The chrome is Vesper. You get a modern independent browser without giving up the web platform and extension ecosystem you already know.

Quiet by default.

Telemetry stays off. Tracking protection is strict. HTTPS-Only and DNS over HTTPS are on. You can loosen what you need — the noisy bits stay locked.

No telemetry

Studies, Normandy, and health-report submission are locked off.

HTTPS-Only + DoH

Encrypted by default, with Quad9 DNS and a system fallback.

Fingerprinting protection

Firefox FPP, not full RFP — strong enough for daily driving without breaking the web.

Read the privacy defaults. Vesper is not affiliated with Mozilla or the Zen OSS Team.
