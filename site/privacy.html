Privacy defaults

Vesper is meant to be a daily driver that is quieter than Firefox, without the breakage of Tor Browser or full Resist Fingerprinting.

Locked

These stay off. They cannot be turned back on in about:config:

  • Telemetry, studies, and Normandy
  • Health report / data submission
  • “More from Mozilla” and VPN promo chrome

On by default, overridable

  • Strict tracking protection, including social and email tracking
  • Firefox Fingerprinting Protection (FPP), not full RFP
  • HTTPS-Only Mode
  • DNS over HTTPS via Quad9, with system DNS fallback
  • Cross-origin referrers trimmed to the host
  • Prefetch, DNS prefetch, and speculative connections off
  • Query stripping and bounce-tracking protection
  • Cookie banners set to reject when possible
  • Safe Browsing lists on; Google download-hash lookup off
  • Mozilla-signed add-ons required

Why not Resist Fingerprinting?

Full RFP is stronger, and it also breaks canvas, timezone, many sites, and some extensions. Vesper ships FPP instead. You can enable RFP in about:config if you want that tradeoff.

Accounts and Sync

Firefox Sync is opt-in. Vesper does not create an account for you.

Add-ons

Vesper keeps Firefox’s application ID so extensions from addons.mozilla.org keep working. Branding is the name and icon; compatibility is the GUID.
